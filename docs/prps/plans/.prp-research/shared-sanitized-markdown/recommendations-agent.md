Keep `marked@^15` so render output stays the same and the regression surface stays small.                                                                                                                      |
| Content-Security-Policy (`kit.csp`)                                  | Defense in depth, not the primary control. Needs report-only rollout and hydration/inline-script testing across all routes. Separate follow-up.                                                                                                                                                         |
| Link `target="_blank"` / `rel` changes                               | Links stay same-tab (FS rule 6). No UX change inside a security refactor.                                                                                                                                                                                                                               |
| Remote-image privacy (referrer policy, proxy, opt-out)               | IP leak only, no script risk. Needs a product decision. `img[src]` stays http/https/relative.                                                                                                                                                                                                           |
| Full `{@html}` / Table `html:` cell audit beyond confirmed fields    | Only the confirmed unescaped producers get `escapeHtml`: metadata-profiles name/description and delay-profiles name. Logs, upgrades and other table interpolations (`row.level`, `row.logger`, info labels) go to a follow-up issue. Other files only get justified disable comments, no logic changes. |
| Consolidating duplicate `escapeHtml` helpers                         | Refactor churn across unrelated files. Follow-up.                                                                                                                                                                                                                                                       |
| Markdown-rendering only `isMarkdownField` in diff tables             | Changes what users see for regex/naming fields. | Non-Svelte HTML assembly (notification/email templates, `innerHTML`) | Outside the scope of the `{@html}` lint rule. | Heading-hierarchy / a11y redesign in cards                           | Visual parity required.
