## URL policy guardrails

Applied inside `safeAttrValue(tag, name, value, cssFilter)` only for `a[href]`, `img[src]`; other attrs → `escapeAttrValue(value)` unchanged.

1. **Decode once**: `const v = friendlyAttrValue(value)` (entities + strips nothing else). Never loop-decode; never `decodeURIComponent` (`%3A` stays literal → path, not scheme).
2. **Reject control chars**: if `/[\u0000-\u001F\u007F]/.test(v)` on decoded value **or** original `value` → return `''`. Also trim-check: if `v !== v.trim()` with leading whitespace before a scheme-like prefix → reject (simplest: reject any leading/trailing whitespace). Must run before `new URL` (parser silently strips tab/LF/CR and leading C0, turning `jav\tascript:` into `javascript:`).
3. **Reject network-path / backslash**: `v.startsWith('//')` or `v.includes('\\')` → `''`.
4. **Scheme detection**: `const m = /^([a-zA-Z][a-zA-Z0-9+.-]*):/.exec(v)`.
   - **No match** → relative (`/p`, `../p`, `guide.md`, `?q`, `#f`, `./a:b`). `img[src]` rejects fragment-only `#…`. Accept → step 6.
   - **Match** → step 5.
5. **Scheme check via parser**: `let p; try { p = new URL(v, 'https://placeholder.invalid').protocol } catch { return '' }`. Require `p === m[1].toLowerCase() + ':'` (guards parser/regex disagreement) **and** `p ∈ {'http:','https:','mailto:'}` for `href`, `{'http:','https:'}` for `src`. Else `''`.
6. **Serialize**: `return escapeAttrValue(v)`. Never return original `value` after rejection; never concatenate.
7. **Rejected outcome**: empty attribute (`''`) — `xss` drops/empties it; link text / `alt` preserved. No throw, no log of payload.
8. Single const `ALLOWED_HREF_PROTOCOLS` / `ALLOWED_SRC_PROTOCOLS` (mirror `ALLOWED_HTTP_SCHEMES` as-const style at `lib/server/utils/validation/url.ts:6`).

ASSUMPTION — needs validation: `xss@1.0.15` invokes `safeAttrValue` with the raw (entity-encoded) attribute value and does not pre-apply its own default URL filter when overridden; verify against published `lib/default.js` / `lib/xss.js`.
