## UX Design

### Before

- 7 client sinks call `marked` directly, `{@html}` unsanitized: `lib/client/ui/display/Markdown.svelte:2,8,18`, `lib/client/ui/form/MarkdownInput.svelte:3,113-114,206`, `routes/custom-formats/[databaseId]/views/CardView.svelte:6,74,195`, `.../custom-formats/[databaseId]/views/TableView.svelte:11,95,153`, `routes/regular-expressions/[databaseId]/views/TableView.svelte:8,32,86`, `routes/databases/[id]/changes/components/FieldDiffTable.svelte:4,16,194,248`, `.../TestsDiffTable.svelte:4,54,112-124`.
- Server path: regex `sanitizeHtml` in `lib/server/utils/markdown/markdown.ts:10-90` (drops all attrs except `a[href,title]`, `img[src,alt,title]`; drops `input`); feeds QP cards `routes/quality-profiles/[databaseId]/views/CardView.svelte:141` via `lib/server/pcd/entities/qualityProfiles/list.ts:182`, TRaSH `lib/server/trashguide/displayTransform.ts:245`, README `routes/databases/[id]/config/+page.server.ts:36`.
- Wrappers: `.markdown` span `Markdown.svelte:13` (+ `maxLines` clamp :14-15); `.prose-inline line-clamp-2` `CardView.svelte:194`; `.prose-inline` span in table html strings; `.prose prose-sm` (hand-written in `app.css:91-335`, no typography plugin) at diff tables + `MarkdownInput.svelte:204`.
- Raw marked output (verified marked 15, `node`): fenced code `<pre><code class="language-js">`; task list `<input checked="" disabled="" type="checkbox">`; tables `<th align="left">`; `[x](javascript:…)` emitted as live `<a href="javascript:…">`; `<details>` passed through.
- Links same-tab: no `target`/`rel` at any call site.

### After

- All sinks call `parseMarkdown` (block) / `parseMarkdownInline` from `$shared/markdown/markdown.ts`; server `$utils/markdown/markdown.ts` re-exports (feature-spec.md:5, :43-44).
- Allowlist tags/attrs per feature-spec.md:47; URL policy :48; no `class/style/id/target`.
- Call-site wrappers, inline-vs-block choice, `line-clamp-2`/`maxLines` unchanged (spec :57-64 edge cases; research-ux.md "Must" #2).
- `MarkdownInput` placeholder `<p class="… italic">Nothing to preview</p>` stays outside sanitizer (spec :59).
- QP/TRaSH double path: server-sanitized HTML re-sanitized client-side, must be idempotent (spec :58).
- Links still same-tab, no `rel` added (spec :49).
